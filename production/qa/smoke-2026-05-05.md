## Diagnostic — Pourquoi le full-suite échoue mais l'isolé passe

**Pattern observé** : tous les tests non-Combat échouent avec erreurs ligne 0 (setup discovery) **uniquement quand exécutés dans la même invocation cmdtool** que les autres suites.

| `integration/menu/state_sync_connect_deferred_test` | 18 | 0 | Signal connection reuse |
| `integration/menu/pause_menu_buttons_test` | 18 | 0 | idem |
| `unit/menu/apply_visibility_test` | 12 | 0 | idem |

**Hypothèse forte** : autoloads (`InputManager`, `GameStateManager`, `LevelSystem`, `AudioSystem`, `SaveLoadSystem`, `AccessibilityService`) ne sont **pas réinitialisés** entre suites. State accumulé d'une suite à l'autre fait crasher le `before_test()` des suites suivantes.

**Note** : ce pattern est dormant depuis longtemps (le projet n'a jamais lancé l'intégralité de la suite en un seul `--add`). CI workflow `.github/workflows/tests.yml` lance probablement par groupes (à vérifier).
